EBAC - Backend Java Persistencia

Repositorio de prácticas y ejercicios del programa Profesión Desarrollador Full Stack Java de EBAC, enfocados en persistencia de datos y desarrollo Backend con Java.

Estructura del repositorio

El repositorio está organizado por módulos. Cada carpeta contiene un proyecto Maven independiente.

Módulo 59 - Persistencia I

Proyecto enfocado en el manejo de persistencia de datos mediante Java y MySQL.

Contenido

Operaciones de acceso a datos.

Conexión a MySQL mediante JDBC.

Organización de clases y modelos.

Ejercicios de persistencia.

Módulo 60 - Persistencia II

Proyecto enfocado en el manejo de persistencia con diferentes tecnologías.

Contenido

JPA e Hibernate.

EntityManager y EntityTransaction.

Criteria API.

Operaciones CRUD con MySQL.

Integración con MongoDB.

Operaciones CRUD sobre documentos.

Tecnologías utilizadas

Java 17

Maven

MySQL

JDBC

JPA

Hibernate

MongoDB

IntelliJ IDEA

Organización técnica

Cada módulo mantiene su propia estructura de proyecto Maven, incluyendo su archivo pom.xml, código fuente y configuración correspondiente.

Esto permite trabajar y ejecutar las prácticas de manera independiente sin mezclar dependencias ni configuraciones.
